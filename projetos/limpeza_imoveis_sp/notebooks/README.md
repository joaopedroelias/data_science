# Notebooks

Esta pasta guarda o notebook do projeto, com toda a etapa de exploração, limpeza, filtragem e análise dos dados.

## Arquivo
- limpeza_analise_imoveis_sp.ipynb

## Etapas do notebook
1. Exploração inicial dos dados
2. Limpeza (duplicatas, tipos, coordenadas inválidas, nomes de colunas)
3. Detecção e tratamento de outliers
4. Filtragem de venda e aluguel
5. Criação de novas colunas (ex: preço por m²)
6. Análise por distrito
7. Exportação do dataset limpo para data/processed

## Como abrir
Abra o arquivo .ipynb diretamente no GitHub para visualizar, ou use o Google Colab para executar o código.
