 Dados brutos

Esta pasta guarda os dados originais do projeto. Os arquivos aqui não devem ser alterados.

## Arquivo
- sao-paulo-properties-april-2019.csv

## Fonte
Dataset "São Paulo Real Estate, Sale/Rent, April 2019", disponibilizado no Kaggle.

## Descrição
13.640 anúncios de apartamentos da cidade de São Paulo, com 16 colunas, incluindo anúncios de venda e de aluguel em 96 distritos.

## Observação
Toda a limpeza é feita no notebook, e o resultado é salvo na pasta data/processed.
